# PROJECT RULES

## General

Write production-quality code.

Avoid unnecessary complexity.

Keep modules independent.

Prefer readability over cleverness.

---

## Architecture

Business logic must not depend on UI.

API must be REST-first.

Database access only through services.

No duplicated logic.

---

## Documentation

Every architectural change must be documented.

Documentation must always match implementation.

---

## Git

Small commits.

Meaningful commit messages.

Never commit temporary files.

---

## AI Collaboration

AI should always:

- read AI_START_HERE.md
- read PROJECT_STATUS.md
- follow PROJECT_CONTEXT.md
- update documentation after major changes

## Quality

Use type hints.

Write modular code.

Follow consistent naming.

Keep functions short.

Prefer explicit code.
