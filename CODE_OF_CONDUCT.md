# Code of Conduct

## Our Pledge

We are committed to creating a welcoming, respectful and professional environment for everyone contributing to Anvero.

## Our Standards

Examples of positive behavior:

- Be respectful.
- Be constructive.
- Focus on solving problems.
- Accept feedback professionally.
- Help improve the project.

Examples of unacceptable behavior:

- Harassment or discrimination.
- Personal attacks.
- Offensive language.
- Intentionally disruptive behavior.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

## Contact

For questions regarding this Code of Conduct, contact the project maintainers.
