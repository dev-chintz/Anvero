## 📊 Key Assumptions

1. **Database:** PostgreSQL will be used from Faza 2 onwards
   - Dev phase may use SQLite
   - Production must use PostgreSQL 16+

2. **Security Model:**
   - JWT tokens expire in 30 minutes (configurable)
   - Refresh tokens: Phase 2+
   - Rate limiting: in-memory (no Redis required)

3. **Auth Flow:**
   - Register → User created (is_active=true)
   - Login → JWT token returned
   - Protected endpoints require Bearer token
   - Token validation: decode + DB check (is_active)

4. **Scope:** Frontend is NOT part of Sprint 2
   - Sprint 2 focus: backend stability only
   - Frontend: Sprint 4+

5. **Testing Strategy:**
   - Unit tests: isolated, fast (SQLite)
   - Integration tests: with real DB (PostgreSQL in CI)
   - E2E: swagger UI + manual testing
